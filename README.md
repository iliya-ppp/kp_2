

## Этап 1

### 1. Назначение программы
Программа предназначена для автоматизированного сбора, фильтрации и статистического анализа телеметрических данных, поступающих с датчиков давления сырья. На основе математических моделей программа пересчитывает физическое давление \(X\) (в барах) в интегральный показатель эффективности \(Q(X)\), осуществляет непрерывный скользящий контроль выхода параметров за технологические границы (LCL/UCL) и формирует аналитическую сводку по выбранному временному окну (с 11 по 37 итерацию).

## Этап 2

### 2. Алгоритм работы программы

1. **Циклический ввод данных:** программа запускает цикл из (N=60) шагов. На каждом шаге:
    * Запрашивается ввод значения давления (X).
    * Выполняется проверка ввода (проверка на числовое значение и нахождение в физическом диапазоне (1.0 <= X <= 12.0)).
2. **Расчет индикатора:** Для (X) вычисляется значение (Q(X)) по кусочно-заданной функции.
3. **Накопление телеметрии:** Если текущий индекс шага попадает в целевое окно контроля (11 <= i <= 37), вычисленное значение накапливается в сумму и счетчик шагов для последующего анализа.
4. **Итоговая статистика:** По завершении ввода всех 60 точек программа вычисляет итоговое среднее значение для окна контроля и определяет количество элементов, превысивших это среднее.


### 3. Организация данных

| Данные | Назначение | Структура |
| :--- | :--- | :--- |
| **X** | Текущее показание датчика давления (бар) |  `double` |
| **Q** | Текущее преобразованное значение  |  `double` |
| **sub_array** | Накопленная телеметрия в окне контроля (с 11 по 37 шаг) |  (`double`) |
| **base_q0** | Базовое  значение индикатора (\(Q_0 = 44.39\)) | `double` |
| **min_allowed (LCL)** | Нижняя контрольная граница  (\(Q_0 *0.95\)) | `double` |
| **max_allowed (UCL)** | Верхняя контрольная граница  (\(Q_0 *1.05\)) | `double` |

### 4. Математическая модель и пример расчета
Расчет индикатора Q(X) производится по следующим математическим зависимостям в зависимости от диапазона давления:

*   **При 1.0 <= X <= 4.0:** 
    Q(X) = (X - 4.0) / 2.0 + Q0
*   **При 4.0 < X <= 8.0:** 
    Q(X) = 4.0 * ln(X - 4.0) + 40.0
*   **При 8.0 < X <= 12.0:** 
    Q(X) = 3.0 * sqrt(X - 7.0) + 65.0

**Примеры ручного расчета для верификации:**

*   **Пример 1 (Нижний диапазон):** X = 2.0 бар (попадает в ветку <= 4.0)
    Q(2.0) = (2.0 - 4.0) / 2.0 + 44.39 = -1.0 + 44.39 = 43.39

*   **Пример 2 (Средний диапазон):** X = 5.0 бар (попадает в ветку от 4.0 до 8.0)
    Q(5.0) = 4.0 * ln(5.0 - 4.0) + 40.0 = 4.0 * ln(1) + 40.0 = 4.0 * 0 + 40.0 = 40.00

*   **Пример 3 (Верхний диапазон):** X = 11.0 bar (попадает в ветку > 8.0)
    Q(11.0) = 3.0 * sqrt(11.0 - 7.0) + 65.0 = 3.0 * sqrt(4) + 65.0 = 3.0 * 2 + 65.0 = 71.00

Контроль параметров осуществляется путем сравнения вычисленного значения \(Q\) с границами технологического коридора допуска:
*   **LCL (Нижняя граница):** \(44.39 * 0.95 = 42.1705\)
*   **UCL (Верхняя граница):** \(44.39 * 1.05 = 46.6095\)

#### Таблица состояний системы контроля:

| Условие | Состояние | Описание |
| :--- | :--- | :--- |
| (42.1705 <= Q <= 46.6095) | **NORMAL** | Процесс стабилен. |
| \(Q < 42.1705\) | **WARNING** | Критическое падение давления. |
| \(Q > 46.6095\) | **WARNING** | Опасный рост индикатора. |
